## 1. רקע ומיצוב

### המתחרה

`פז"מ` היא האפליקציה המובילה בתחום: 4.9★ מ-11,000 דירוגים ב-App Store,
קיימת כ-13 שנה, iOS ו-Android. הפיצ'רים שלה:

| קטגוריה | מה יש |
|---|---|
| ליבה | ספירה לשחרור בחודשים/שבועות/ימים/דקות/שניות |
| אירועים | חג הבא, כומתה, סוף מסלול, דרגה, ימי הולדת, ספירות מותאמות |
| מידע | מדריך דרגות/סמלים/כומתות, "גלאי מ"צ", ויקי צה"ל |
| התאמה | אווטאר, אייקון לכל ספירה |
| חברתי | סטיקרים לוואטסאפ/אינסטגרם, "קרבות פז"מ", ימי הולדת של חברים |
| בידור | משחקים, "צעקות" קוליות, חנות והנחות |
| מערכת | וידג'טים למסך הבית, מנוי `פז"מ+` |

### ההחלטה

כמחצית מהערך של פז"מ הוא קהילה, תוכן ומסחר — כל אלה דורשים שרת, חשבון ומנוי,
ונמצאים מחוץ להגדרת הריפו (כלי אופליין בקובץ HTML יחיד).

**אנחנו מתחרים בליבה בלבד — הספירה עצמה — ומנצחים בכך שאיננו עושים את השאר:**
בלי פרסומות, בלי מנוי, בלי חשבון, בלי הרשאות, טעינה מיידית, נתונים על המכשיר בלבד.

**מה במפורש לא נכנס:** קרבות פז"מ, משחקים, סטיקרים, אווטארים, חנות, ויקי,
גלאי מ"צ, מנוי.

### החלטות שנשקלו ונדחו (07/08/2026)

עלתה הצעה להסב את הכלי לאפליקציה נייטיבית (React Native / Flutter) עם
SQLite/SQLCipher, מפתח ב-iOS Keychain / Android Keystore, ונעילה ביומטרית.
**נדחתה.** הנימוקים, לתיעוד:

- **סתירה לריפו.** `Learning-` הוא אוסף כלים שרצים בדפדפן ומתפרסמים כאתר
  GitHub Pages אחד. אפליקציה נייטיבית לא יכולה לחיות בו — אין תיקייה, אין
  כרטיס בנחיתה, `verify-all.mjs` לא חל עליה, והפריסה לא נוגעת בה. זה פרויקט
  אחר, לא כלי באוסף.
- **Keychain / Keystore אינם נגישים לדף אינטרנט.** אין דרך ל-PWA לשמור מפתח
  ברכיב החומרה המאובטח. מגבלת פלטפורמה, לא בחירה.
- **הצפנה בדפדפן אפשרית אך לא מידתית כאן.** קיים תקדים בריפו (`/admin/`,
  AES-256-GCM + PBKDF2), אבל שם המפתח נגזר מסיסמה שהמשתמש מקליד — כלומר
  סיסמה בכל פתיחה. הנתונים כאן הם תאריך גיוס, תאריך שחרור ותאריכי קורסים:
  לא אישורי גישה, לא מידע רפואי, לא מיקום. החיכוך וסיכון הנעילה גדולים
  מהתועלת.
- **SQLite / WatermelonDB** הן ספריות React Native. מקבילת הדפדפן היא
  IndexedDB, אך לנפח הנתונים כאן (פרופיל + עשרות אירועים, פחות מקילובייט)
  `localStorage` הוא הבחירה הנכונה. IndexedDB הוא מסלול השדרוג אם אי-פעם
  יידרשו שאילתות או נפח.

מה שכן אומץ מאותה הצעה: סעיף המשאבים החיצוניים (§3).

### עובדות רקע לחישוב

הכנסת אישרה ב-07/2026 ששירות החובה יעמוד על **32 חודשים** (ולא 36 כפי שצה"ל
ביקש), לכל המתגייסים עד יולי 2029. לנשים — 24 חודשים. שני המספרים משמשים רק
כ**הצעה** בכפתור "חשב לי" שבאשף הפתיחה; מקור האמת הוא תמיד מה שהמשתמש הזין
(ראה §4, "אשף פתיחה").

## 3. ארכיטקטורה

`index.html` עצמאי אחד. בלי בנייה, בלי תלויות, בלי גישה לרשת.

| מודול | אחריות | תלויות |
|---|---|---|
| `dates` | חשבון תאריכים טהור: ימים בין תאריכים, הוספת חודשים, אחוז התקדמות, ניסוח עברי | אין (פונקציות טהורות) |
| `store` | קריאה/כתיבה ל-`localStorage`, מיגרציית גרסה, ייצוא/ייבוא | `dates` |
| `render` | בניית ה-DOM מהמצב | `dates`, `store` |
| `motion` | התכווצות הגיבור בגלילה, גלגול ספרות | אין |

`dates` מבודד בכוונה: זהו המודול היחיד שבו באג פוגע במספר הראשי במסך, והבידוד
הוא מה שמאפשר לבדוק אותו ב-Node ללא דפדפן.

### מודל הנתונים

מפתח `localStorage` יחיד: `service-countdown.v1`

```js
{
  v: 1,
  profile: {                 // null אם המשתמש דילג על האשף
    enlistDate:  "2025-03-15",   // ISO date, ללא שעה
    releaseDate: "2027-11-15",
    gender: "m" | "f" | null     // נשמר רק כדי לזכור את בחירת "חשב לי"
  },
  events: [
    { id, title, date, icon, source: "template" | "custom" }
  ],
  heroId: "release" | "<event id>",
  theme:  "dark" | "light"
}
```

תאריכים נשמרים כ-`YYYY-MM-DD` בלבד (בלי שעה, בלי אזור זמן) — אירוע הוא יום,
לא רגע. זה מונע מחלקה גדולה של באגי אזור-זמן במקור.

**`icon`** הוא מפתח מתוך סט אייקוני Lucide המוטמעים בעמוד (למשל `"graduation-cap"`),
לא markup.

**השחרור אינו רשומה ב-`events`.** הוא אירוע וירטואלי בעל `id: "release"` הנגזר
מ-`profile.releaseDate`, ומוצג לצד שאר האירועים. הסיבה: כך יש מקור אמת אחד
לתאריך השחרור, שממנו נגזרים גם ציר הזמן וגם אחוז הפז"מ.
תבנית "שחרור" בספריית התבניות (§4) קיימת עבור מי שדילג על האשף ואין לו פרופיל;
בחירתה **מגדירה את הפרופיל** במקום ליצור אירוע כפול.

**`heroId` שאינו קיים** (למשל `"release"` בלי פרופיל, או אירוע שנמחק) נופל חזרה
לאירוע הקרוב ביותר, ואם אין כזה — למצב הריק.

### משאבים חיצוניים — אפס

הכלי חייב לרנדר במלואו במצב טיסה, מהטעינה הראשונה ואילך. לכן, **אף בקשת רשת
אינה מותרת** — לא CDN, לא Google Fonts, לא תמונות מרוחקות, לא API, לא SDK של
צד שלישי, לא טלמטריה.

| משאב | מדיניות |
|---|---|
| גופנים | מחסנית גופני מערכת בלבד, לפי הקונבנציה בריפו: `system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans Hebrew", Arial, sans-serif`. **אין הטמעת קובץ גופן ואין Google Fonts** |
| אייקונים | Lucide כ-SVG inline, מוטמעים בעמוד |
| גרפיקה | SVG inline או `data:` URI. בהטמעת SVG כ-`data:` URI — לקודד `#` ל-`%23`, ולא לעטוף ב-`url('...')` אם ה-SVG מכיל מרכאות יחידות (מלכודת מתועדת ב-`PROJECT_LESSONS`) |
| קוד | אפס תלויות, אפס שלב בנייה |

זהו קריטריון שניתן לאימות: `verify-all.mjs` מריץ רינדור headless ומדווח על
שגיאות קונסולה, ובקשת רשת כושלת במצב אופליין תיתפס שם.

## 4. מסכים ופריסה

הפריסה הנבחרת: **גיבור מלא-מסך, ציר הזמן נחשף בגלילה.**
נשקלו גם מסך נגלל אחד וטאבים; נדחו כי הגיבור מתחרה על תשומת לב במקרה הראשון,
והשני גנרי.

### אשף פתיחה

מוצג רק בכניסה ראשונה, ניתן לדילוג. שני צעדים:

1. תאריך גיוס
2. תאריך שחרור — ולידו כפתור **"חשב לי"** שפותח צ'יפ מין
   (חייל 32 חודשים / חיילת 24) וממלא הצעה הניתנת לדריסה.

דילוג מותר: הכלי עובד בלי פרופיל (ראה §6).

### מסך הגיבור

`100dvh` (לא `vh` — סרגלי הדפדפן במובייל שוברים אותו), ממורכז, כמעט ריק:

```
                    שחרור
                     412
                     ימים
              ─────◯──────────
              14 באוגוסט 2027 · 47%
                      ⌄
```

- מספר הימים בטיפוגרפיה ענקית (`clamp()`, מ-20vw)
- טבעת התקדמות דקה סביבו (רק אם יש פרופיל)
- תאריך היעד ואחוז הפז"מ
- `⌄` רמז גלילה

### ציר הזמן

נחשף בגלילה. ציר אנכי RTL מהגיוס לשחרור, החלק שעבר צבוע באקסנט, סמן "אתה כאן",
ונקודות אירועים ממוקמות לפי תאריך. אירועים שעברו מעומעמים.

**אבני דרך אוטומטיות** (נגזרות מהפרופיל, לא ניתנות לעריכה):
25%, חצי פז"מ (50%), 75%, שנה, שנתיים, 100 הימים האחרונים.

### רצועת האירועים

כרטיסים ממוינים מהקרוב לרחוק, כל אחד עם מספר הימים שלו. כל אירוע בתוך 7 ימים
מסומן ("מה קרוב"). **לחיצה על כרטיס הופכת אותו לגיבור** — כך "סוף קורס מפקדים"
נעשה המספר הראשי בתקופה שבה זה מה שמעניין.

### הוספת אירוע

גיליון עם ספריית תבניות בלחיצה — התבנית ממלאת שם ואייקון, המשתמש בוחר תאריך:

`סוף טירונות · מסע כומתה · סוף אימון מתקדם · סוף מסלול · קורס מפקדים ·
קורס קצינים · דרגה חדשה · רגילה הבאה · הביתה · שחרור`

בנוסף אפשר אירוע חופשי (שם + תאריך + אייקון).

### הגדרות

מצב תצוגה (כהה/בהיר), עריכת פרופיל, ייצוא/ייבוא JSON, איפוס.

### אייקונים

קו-inline מ-Lucide בלבד. **לא אימוג'י, לא SVG מצויר ביד** — לפי חוקי הריפו.

## 5. מוֹשן

- **התכווצות הגיבור בגלילה:** מאזין גלילה מווסת ב-`requestAnimationFrame`
  שכותב משתנה CSS `--t` בטווח 0–1; הגיבור מתכווץ לכותרת דביקה.
  **במפורש לא `animation-timeline: scroll()`** — אין לו תמיכה רוחבית, ובפרט
  לא ב-iOS Safari, שהוא יעד עיקרי לכלי PWA.
- **גלגול ספרה** בשינוי מספר הימים ובטעינה.
- **`prefers-reduced-motion` מכובד** — הכול נחתך למעברי אטימות.

## 6. קצוות והתנהגות מוגדרת

| מצב | התנהגות |
|---|---|
| התאריך עבר | הגיבור מתהפך ל"משוחרר" וסופר **קדימה** מאז — לא `0-` ולא קריסה |
| מעבר שעון קיץ | ספירת ימים בין **חצות מקומי** לחצות מקומי, עם עיגול — לא חילוק במילישניות. אחרת יום המעבר נותן טעות של יום שלם במספר הראשי |
| גלישת סוף חודש | ב-JS, 31/03 + חודש = 01/05. "חשב לי" יצמיד לסוף החודש |
| שנה מעוברת | 29/02 מטופל דרך אותה הצמדה |
| ניסוח עברי | "נשאר יום אחד" / "נשארו יומיים" / "נשארו 3 ימים" — לא "1 ימים" |
| אין פרופיל | הגיבור = האירוע הקרוב; ציר הזמן וטבעת האחוז מוסתרים |
| אין אירועים כלל | מצב ריק ייעודי עם קריאה לפעולה |
| שחרור לפני גיוס | ולידציה באשף, הודעת שגיאה, לא נשמר |
| `localStorage` חסום/מלא | הכלי עובד לסשן הנוכחי ומציג הודעה שהנתונים לא יישמרו |
| ייבוא JSON פגום | נדחה עם הודעה; המצב הקיים לא נדרס |

### התראות — מגבלה מוצהרת

**התראות מתוזמנות ("תזכיר לי יום לפני") לא ייתמכו.** תזמון התראה מקומית
בדפדפן דורש שרת Web Push, ו-API התזמון המקומי אינו נתמך בפועל.
**החלופה:** סימון "מה קרוב" (7 ימים) בפתיחת הכלי.

זהו פער אמיתי מול המתחרה. אם יתברר כחסר קריטי, הפתרון היחיד הוא שרת Push —
וזה יוצא מהגדרת הריפו ומחייב החלטה נפרדת.

## 7. בדיקות

### בדיקת יחידה

`service-countdown/test/dates.test.mjs` — Node, ללא תלויות, בדפוס הקיים בריפו
(`guard-duty-scheduler/test/scheduler.test.mjs`): חילוץ המקור **האמיתי** של
`dates` מתוך `index.html` ב-regex והרצתו ב-`node:vm`, כך שהבדיקה לא יכולה
להיסחף בשקט מהקוד שרץ בדפדפן.

```bash
node service-countdown/test/dates.test.mjs
```

כיסוי: מעבר שעון קיץ, גלישת סוף חודש ב-"+32 חודשים", שנה מעוברת, אחוז בגבולות
(0% / 100% / אחרי שחרור), ניסוח עברי לכל הצורות, ושחרור לפני גיוס.

### שער האיכות

```bash
node .claude/tools/verify-all.mjs
```

מבנה, `manifest` תקין, רישום service worker, קישור מהנחיתה, ורינדור headless
באור ובחושך (שגיאות קונסולה + גלישה אופקית). אותו סקריפט רץ ב-CI על הענף.

### ידני

מעבר על האשף (כולל דילוג), הוספת אירוע מתבנית, החלפת גיבור, ומתג התצוגה.

## 9. קריטריוני הצלחה

1. פתיחת הכלי מציגה מספר אחד גדול ונכון תוך פחות משנייה, אופליין.
2. `node service-countdown/test/dates.test.mjs` עובר.
3. `node .claude/tools/verify-all.mjs` ירוק.
4. עובד ונראה נכון באור ובחושך, בלי גלישה אופקית ובלי שגיאות קונסולה.
5. ניתן להתקנה כ-PWA למסך הבית ולעבוד ללא רשת.
6. **אפס בקשות רשת** — לוח ה-Network בטעינה חוזרת
   ריק מבקשות חיצוניות, והכלי מתפקד במלואו במצב טיסה.
